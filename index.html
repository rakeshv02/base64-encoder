Frequently Asked Questions

What is Base64?
Base64 is an encoding scheme that converts binary data into ASCII text — commonly used for sending data in HTML, CSS or APIs.
Is my data sent to a server?
No — all encoding/decoding happens in your browser using JavaScript's btoa/atob. Nothing leaves your device.
Is this free?
Yes — completely free, no sign-up needed.
Can I encode files?
Yes — use the File tab to convert any file to base64. Great for embedding images in CSS or HTML.
